### Getting started

Visit [https://strudel.cc/](https://strudel.cc/) and edit the code in the REPL.

**Play** the script with <kbd>Ctrl</kbd> + <kbd>Enter</kbd>. Also, after making changes to the code, use this shortcut to update the generated audio.

**Stop** the script with <kbd>Ctrl</kbd> + <kbd>.</kbd>.

Read their docs [here](https://strudel.cc/workshop/getting-started/).

### Basics

#### Playing simple sounds

Make a chiptunes-y "beep" sound once per unit of time:

```js
sound("casio")
```

Try replacing `"casio"` with these other sound names:

- `"insect"`
- `"wind"`
- `"jazz"`
- `"metal"`
- `"east"`
- `"crow"`
- `"space"`
- `"numbers"`

#### Making simple patterns

To make a simple pattern of sounds, simply separate sound names by spaces. For example:

```js
sound("casio crow")
```

You may notice that these sounds are played twice as fast as those played by `sound("casio")`. That's because, by default, Strudel subdivides the duration of the time unit by the number of sounds it needs to play. So if it only has to play 1 sound, then that sound will be allowed to take up the full duration of the time unit. Or if it must play 2 sounds, then those sounds will each be allowed to take up half a unit's worth of time. As you can probably guess, then, the following code will cause sounds to be played 4 times as fast as `sound("casio")`:

```js
sound("casio crow metal east")
```

#### Selecting specific samples

Some sounds contain multiple samples. Using `sound("casio")`, for example, is the same as using the 0th sample in the set and is identical to `sound("casio:0")`. Replace `0` with other numbers to access other samples. For example:

```js
sound("casio:3")
```

#### Playing drum samples

Strudel uses the following acronyms to represent drum sounds:

- `"bd"` = bass drum
- `"sd"` = snare drum
- `"rim"` = rimshot
- `"hh"` = hihat
- `"oh"` = open hihat
- `"lt"` = low tom
- `"mt"` = middle tom
- `"ht"` = high tom
- `"rd"` = ride cymbal
- `"cr"` = crash cymbal

So, for example:

```js
sound("bd hh sd oh")
```

#### Changing sound banks

We can change which sound bank is used to play samples like this:

```js
sound("bd hh sd oh").bank("RolandTR909")
```

#### Working with time

As mentioned above, the default behavior of Strudel is to subdivide each time unit by the number of sounds it needs to play. However, this behavior can be overridden by using angle brackets (`<` and `>`).

First, let's start with this pattern:

```js
sound("bd bd hh bd rim bd hh bd")
```

We'll wrap it in angle brackets:

```js
sound("<bd bd hh bd rim bd hh bd>")
```

Instead of playing 8 sounds in a single time unit, the above pattern causes each individual sound to receive a full time unit (which is awfully slow)! We can speed it back up, though, by "multiplying" the pattern by some number:

```js
sound("<bd bd hh bd rim bd hh bd> * 8")
```

Now, even though the above pattern — which has 8 sounds, wrapped in angle brackets, and then made 8 times as fast — ends up sounding exactly the same as the original version (with no angle brackets), there's one significant difference: **When using angle brackets, time units are no longer subdivided equally among the given sounds.** In the above pattern, each sound is allowed to last for 1/8 of a time unit. If we added another sound to the pattern _without_ angle brackets, then each sound would be allowed to last for 1/9 of a time unit. But if we add another sound to the pattern _with_ angle brackets, each sound still only lasts for 1/8 of a time unit — even though 9 sounds would be present in the pattern!

> **NOTE:** At least, that's my naive understanding as I write these notes. But I've just started with Strudel, and there may be more nuance or better understanding yet to come.

Finally, we can set the tempo (in cycles per minute) using `setcpm`:

```js
setcpm(90 / 4)
sound("<bd bd hh bd rim bd hh bd> * 8")
```

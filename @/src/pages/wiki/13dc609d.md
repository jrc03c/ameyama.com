Combine PDFs at the command line in Linux using `pdfunite` from [`poppler-utils`](https://poppler.freedesktop.org/).

```bash
# install
sudo apt update
sudo apt install -y poppler-utils

# combine
pdfunite doc1.pdf doc2.pdf doc3.pdf [etc.] combined.pdf
```

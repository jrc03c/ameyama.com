Here are the steps for setting up KeePassXC integration with LibreWolf on Linux:

0. Install LibreWolf, KeePassXC, and the KeePassXC browser extension in LibreWolf.

1. Enable Firefox browser integration in the KeePassXC settings.

2. Symlink Firefox's `native-messaging-hosts` directory into LibreWolf's configuration directory:

```bash
ln -s $HOME/.mozilla/native-messaging-hosts $HOME/.librewolf/native-messaging-hosts
```

3. In LibreWolf, navigate to `about:config` in the URL bar, and set the property `widget.use-xdg-desktop-portal.native-messaging` to have a value of `1`.

4. Restart both KeePassXC and LibreWolf. When LibreWolf reopens, it may ask you to confirm that you want to enable native messaging (though I don't recall the exact wording); and you should confirm it.

5. Finish setting up the KeePassXC browser extension in the usual way!

> **NOTE:** The above steps assume that you're _not_ using the Flatpak version of LibreWolf. If you _are_ using that version, then the overall idea is still the same, but some extra work will be required to make sure (1) that the `native-messaging-hosts` directory is correctly symlinked inside the Flatpak installation and (2) that LibreWolf is given access (via a tool like [Flatseal](https://flathub.org/en/apps/com.github.tchx84.Flatseal)) to that symlinked directory. I haven't tried it recently, though, so I don't recall the exact steps, and I don't feel as confident that it'll work as expected.

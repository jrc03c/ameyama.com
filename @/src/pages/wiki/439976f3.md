### Fix the `apt` "Unable to fetch some archives" error

For whatever reason, running this occasionally produces an "Unable to fetch some archives" error:

```bash
sudo apt update
sudo apt install -y some-package
```

Weirdly, one fix that seems to work is to run the same thing using `apt-get` instead of `apt`:

```bash
sudo apt-get update
sudo apt-get install -y some-package
```
